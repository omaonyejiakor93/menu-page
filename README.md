# Coffee Menu Page

This is a simple and stylish coffee menu web page built using HTML and CSS. It was created as part of a FreeCodeCamp Responsive Web Design certification project.

## Features

- Clean, modern layout
- Lists different coffee options and prices
- Responsive design for both desktop and mobile

## Technologies Used

- HTML5
- CSS3

## How to View

You can:
1. Clone or download this repository
2. Open the index.html file in your browser

## Files Included

- index.html — The menu page structure
- style.css — Styling for the layout and design
